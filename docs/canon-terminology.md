# Canon och terminologi

## Pedagogisk profil

- Språk: Svenska
- Svårighetsgrad: Grundnivå med fördjupningar
- Läsarprofil: Van trädgårdsodlare
- Ton: Personlig, praktisk och kunnig
- Repetitionstakt: Låg till måttlig

## Centrala begrepp

| Begrepp | Första kapitel | Kort definition |
|---|---|---|
| Kväve | Kapitel 1 | Näringsämne som främst driver grön tillväxt |
| Fosfor | Kapitel 1 | Näringsämne kopplat till energi, rötter och utveckling |
| Kalium | Kapitel 1 | Näringsämne som stödjer stadga, frukt, vattenbalans och avmognad |
| Mull | Kapitel 2 | Nedbrutet organiskt material som förbättrar jordens egenskaper |
| Organisk gödsel | Kapitel 3 | Gödsel från växt- eller djurmaterial |
| Mineralgödsel | Kapitel 3 | Gödsel med näringsämnen i mer direkt tillgänglig mineralisk form |
| Grundgödsling | Kapitel 5 | Näring som ges före eller vid plantering och sådd |
| Kompletteringsgödsling | Kapitel 5 | Extra näring under aktiv tillväxt |
| Avmognad | Kapitel 6 | Process där fleråriga växter avslutar tillväxt och förbereder sig för vinter |

## Stilregler

- Behandla ekologisk gödsling och mineralgödsel balanserat.
- Undvik tvärsäkra doseringsråd utan hänsyn till jord och väder.
- Lyft växtzon 5–6 genom timing, kall jord och vinterhärdighet.
- Använd personligt men sakligt tonfall.
