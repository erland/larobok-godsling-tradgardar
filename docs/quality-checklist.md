# Kvalitetschecklista

## Slutredigering

- [x] Undertitel är uppdaterad i centrala metadatafiler.
- [x] Författare är angiven.
- [x] Kapitelordning finns i exportmetadata.
- [x] Alla kapitel använder H1–H3.
- [x] Ingen H4-rubrik används.
- [x] Tonen är personlig och praktisk.
- [x] Boken undviker onödig upprepning.
- [x] Ekologisk gödsling och mineralgödsel behandlas balanserat.
- [x] Växtzon 5–6 syns genom råd om timing, kall jord och avmognad.
- [x] Omslaget är inkluderat.
- [x] Exportpipeline finns för lokal EPUB/PDF/DOCX/Markdown-export.

## Kontroll före slutexport

- [ ] Kör `scripts/export-book.sh`.
- [ ] Kontrollera EPUB i e-boksläsare.
- [ ] Kontrollera PDF: innehållsförteckning, sidbrytningar och tabeller.
- [ ] Kontrollera att omslaget visas korrekt.
